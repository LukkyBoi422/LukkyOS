# VerumOS
> Pronounced **"Fer-um OS"**

VerumOS is an Arch Linux-based distribution focused on simplicity, performance, and privacy.

Built around a custom XFCE desktop environment, VerumOS aims to provide a clean and intuitive experience without sacrificing the flexibility and power of Arch Linux.

## Features

- Based on Arch Linux
- Custom XFCE desktop environment
- Lightweight and performance-focused
- Privacy-focused
- Simple and user-friendly
- Custom tools and configurations
- Rolling-release model

## Philosophy

VerumOS is built around three core principles:

- **Simplicity** — Keep the system clean, straightforward, and easy to use.
- **Performance** — Avoid unnecessary software and resource usage.
- **Privacy** — Respect the user's privacy and provide tools that help users maintain control over their data.
